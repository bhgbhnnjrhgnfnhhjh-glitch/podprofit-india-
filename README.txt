PODProfit India - Step 19 Part 1

Files:
- index.html : complete website code
- robots.txt : crawler instructions
- sitemap.xml : Google sitemap

How to publish:
1. Extract the ZIP.
2. Open your GitHub repository.
3. Upload/replace index.html, robots.txt and sitemap.xml in the repository root.
4. Commit changes.
5. Wait for GitHub Pages to update.
6. Open your live website and test the calculator.

Important:
- Replace YOUR-EMAIL@example.com in index.html with your real contact email before final publishing.
- Platform fees are estimates; users can edit them.
- Currency selector changes the displayed symbol only; it does not convert exchange rates.
