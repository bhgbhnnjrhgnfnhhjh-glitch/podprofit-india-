PODProfit India - Step 28

Step 28 adds a Sales & Profit Forecast section.

New features:
- 7-day, 30-day, 90-day, 6-month and 12-month forecasts
- Estimated orders, revenue, expenses and net profit
- Conservative (75%), current pace (100%) and higher sales (125%) 30-day scenarios
- Forecast automatically updates from the main calculator settings

All Step 27 features are preserved.
No AI, API or external JavaScript library is required.
